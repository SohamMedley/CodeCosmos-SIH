Problem Statement SIH26099Smart Automation · Software

AI-Driven Standardization & Harmonization of Material Codes Across CPSEs

Every CPSE writes the same engineering item differently — Bearing 6205, 6205 Deep Groove Ball Bearing, BALL BEARING, 6205, SKF 6205 BEARING. This engine understands the engineering meaning behind the words, aligns units, scores its own confidence and routes only the uncertain cases to a human expert — ending with one validated material master and a CNMC code.

                      The core idea in one sentence

                      Code Cosmos proposes an AI-driven, human-in-the-loop system that converts inconsistent CPSE material records into standardized material knowledge by combining semantic similarity, fuzzy matching, technical-attribute extraction, unit normalization, confidence scoring, expert validation and CNMC code mapping.

                      Research foundation → what we extend

                      Existing work answers “are these two entities similar?”. This system answers “are they equivalent, what defines them, what should they map to, and how sure are we?”.

                        Prototype disclosure

                        • This build is a 100% client-side prototype: HTML, CSS and vanilla ES modules only — no server, no Python, no external API keys.
                        • The CPSE corpus is synthetic and generated deterministically from engineering concepts, so no real organization's material data is used. Ground truth is retained only to score the engine.
                        • Semantic embeddings are a compact in-browser concept tf-idf + random-projection model standing in for a fine-tuned Sentence-BERT encoder; the interface is identical, so swapping in the production encoder changes only that one module.
                        • CNMC class codes and generated material codes are illustrative mappings for the prototype and must be validated against the official CNMC taxonomy before production use.
