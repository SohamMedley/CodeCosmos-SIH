END-TO-END PIPELINE

From raw to reliable.

A practical path from source descriptions to reusable material knowledge.

01 / INGEST

Bring records together

Import CSV material descriptions with their source and source-system ID.

02 / NORMALIZE

Resolve language variation

Expand known abbreviations, standardize units and align naming conventions.

03 / EXTRACT

Surface technical facts

Identify explicit dimensions, designations, materials, grades and pressure classes.

04 / COMPARE

Build a shortlist

Blend synonym-aware local vectors, fuzzy text and attribute agreement. Groq can enrich up to eight pairs per run.

05 / PROTECT

Block false equivalence

A known spec mismatch prevents a suggestion; missing information is flagged for review.

06 / VALIDATE & MAP

Keep the expert in charge

Approve or reject with notes, link to an imported reference code, export the validated master.

BUILT-IN SAFEGUARDS

What the AI cannot do.

01
Override a spec conflict

6205 is not 6206. M10 × 50 is not M10 × 60. No semantic score can change that.

02
Silently approve a match

Fast-track means prioritized review, never an automatic merge.

03
Invent an official CNMC code

Demo identifiers are clearly marked. Real mapping needs an authorized reference import.

To connect Groq
  1. Get a key from console.groq.com/keys.
  2. Add GROQ_API_KEY in your Render service environment (or local .env).
  3. Redeploy / restart, then enable Groq on a run.
Never place an API key in browser code or a public repository.
DATA & PERSISTENCE

A working prototype, not a black box.

Records, decisions and the audit trail are stored in SQLite. On Render's free instance, local files are ephemeral across redeploys or instance replacement.

For persistent deployment, attach a Render disk on an eligible plan and set DB_PATH to its mount path, or migrate storage to a managed database.
PROTOTYPE SCOPE

Honest by design.

Local vectors are synonym-aware sparse representations, not pretrained neural embeddings. Scores are heuristic rankings, not calibrated probabilities. The demo library is illustrative, not an official CNMC taxonomy.
